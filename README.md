# 青艺云广播 · HarmonyOS

> 把「青艺云广播」装进你的 HarmonyOS 手机：27 个电台、实时节目单、锁屏播放控制、后台持续收听。

一款用 ArkTS / ArkUI 原生开发的 HarmonyOS 电台收听应用。打开即见电台列表，点进播放页，收听历史收在底部半屏弹窗里。浅色弥散渐变底色 + 青绿主色，适配 HarmonyOS NEXT（API 12+）。

## 功能亮点

- **27 个直播电台**：华语、粤语、音乐、资讯等分类，支持按名称/地区/风格搜索与筛选。
- **实时节目单**：每 15 秒拉取 ICY 元数据，切台自动丢弃过期响应，播放页实时显示当前节目。
- **锁屏 / 控制中心**：AVSession 同步电台名、节目信息与播放状态，通知栏可播放、暂停、切台。
- **后台持续播放**：长时任务 + 后台保活，熄屏后继续出声。
- **今日收听历史**：识别到新节目自动记一条，同名单曲去重置顶，跨天自动清空。
- **迷你播放条**：返回列表后仍在底部，可直接暂停/继续，点一下回到播放页。
- **断流自动重连**：出错时自动换协议重试，接口异常时读内置数据兜底，首屏不空白。

## 安装说明

本应用通过侧载方式安装（HAP 安装包 + 本机开发者签名）。

1. 在手机上开启**开发者选项**与**无线调试**。
2. 用轻启安装器或 HDC 工具，选择本仓库 Release 中的 `.hap` 安装包。
3. 使用你自己的 HarmonyOS 开发者证书与 Profile 完成签装（安装包来源的合法性与安全性请自行判断）。
4. 首次启动后，进入任意电台即可开始收听。

> 需要 HarmonyOS NEXT（API 12+）设备。部分电台为 HTTP 明文流，若设备拦截明文请求会自动尝试 HTTPS 版本。
